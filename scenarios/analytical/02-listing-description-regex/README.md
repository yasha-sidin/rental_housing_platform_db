# Поиск по формату описания объявления

## Что выполнялось

Сценарий ищет объявления, описание которых соответствует формату `Seed listing <локация>`, и извлекает локацию из текстового поля регулярным выражением.

SQL-запрос: `request.sql`.

## Полученный результат

Артефакт выполнения находится в `artifacts/result.png`. В результате возвращаются идентификатор объявления, исходное описание, извлеченная локация, статус, вместимость и число комнат.

## Что доказывает сценарий

Сценарий показывает аналитическое чтение текстового атрибута объявления. Регулярное выражение позволяет выделить смысловую часть описания и использовать ее как расчетный признак в отчете.
