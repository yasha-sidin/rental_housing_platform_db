# Аналитические сценарии

Аналитические сценарии проверяют чтение данных и работу индексов. Они отражают типовые задачи эксплуатации платформы: отчет по бронированиям, поиск объявлений, выгрузка активного каталога и анализ планов выполнения.

Состав раздела:

- `01-booking-payment-review-report/` - отчет по бронированиям, платежам и отзывам;
- `02-listing-description-regex/` - извлечение части описания объявления регулярным выражением;
- `03-active-listings-export/` - CSV-витрина активных объявлений;
- `04-index-plan-analysis/` - запросы `EXPLAIN (ANALYZE, BUFFERS)` для ключевых индексов.

Раздел показывает, что схема пригодна не только для записи доменных событий, но и для последующего анализа состояния платформы.
