# Удаление непривязанных служебных фотографий

## Что выполнялось

Сценарий создает служебную фотографию и удаляет только те фотографии, которые не связаны с объявлениями через `listing_photos`. Для связи удаляемой таблицы с проверочной выборкой используется `DELETE ... USING`.

SQL-запрос: `request.sql`.

## Полученный результат

Артефакт выполнения находится в `artifacts/result.png`. На снимке показана удаленная строка с идентификатором, расширением, ссылкой и временем создания.

## Что доказывает сценарий

Модель отделяет сам объект фотографии от привязки фотографии к объявлению. Поэтому очистка должна учитывать связь `listing_photos`: удалять можно только непривязанные служебные фотографии, не нарушая целостность галерей объявлений.
