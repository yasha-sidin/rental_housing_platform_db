# Операционные сценарии

Операционные сценарии проверяют изменения данных, которые характерны для прикладного слоя платформы аренды жилья. Все запросы выполняются в транзакции и завершаются `ROLLBACK`, поэтому их можно использовать для повторной проверки без накопления служебных строк.

Состав раздела:

- `01-insert-returning/` - создание фотографии с возвратом добавленной строки;
- `02-update-availability-price/` - изменение дневной цены через связь календаря, объявления, адреса и базовой цены;
- `03-delete-unlinked-photos/` - удаление непривязанных служебных фотографий через `DELETE ... USING`.

Сценарии показывают не только синтаксис SQL, но и смысл операций для домена: добавление медиаданных, управление ценой календарного дня и очистку данных, не связанных с объявлениями.
