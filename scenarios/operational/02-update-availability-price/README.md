# Изменение дневной цены доступности

## Что выполнялось

Сценарий повышает дневную override-цену для активных объявлений в выбранном городе на ближайшие выходные. Запрос использует `UPDATE ... FROM`, потому что обновляемая таблица `listing_availability_days` должна быть связана с объявлениями, адресами, городами и базовыми ценами.

SQL-запрос: `request.sql`.

## Полученный результат

Артефакт выполнения находится в `artifacts/result.png`. В результате возвращаются идентификатор календарного дня, объявление, город, дата, базовая цена, новая дневная цена и валюта.

## Что доказывает сценарий

Календарь доступности является не изолированным справочником дат, а частью ценовой модели объявления. Запрос показывает, что дневная цена может изменяться с учетом местоположения, статуса объявления и базовой цены, а результат операции возвращает данные для аудита изменения.
