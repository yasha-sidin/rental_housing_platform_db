# Проверочные сценарии доменной модели

Каталог фиксирует SQL-сценарии, которые подтверждают применимость схемы базы данных к предметной области краткосрочной аренды жилья. Сценарии разделены на две группы:

- `operational/` - операции изменения данных: создание записи, изменение календаря доступности, удаление непривязанных служебных данных;
- `analytical/` - чтение и анализ данных: отчеты по бронированиям, поиск по описанию, выгрузка витрины, проверка использования индексов.

Каждый сценарий оформлен одинаково:

- `README.md` описывает, что выполнялось, какой результат получен и что он доказывает;
- `request.sql` или `indexes_explain.sql` содержит SQL-запрос;
- `artifacts/` хранит результат выполнения: снимок результата, CSV-выгрузку или план выполнения запроса.

Эти материалы не являются отдельным приложением. Они показывают, что схема поддерживает прикладные операции и аналитические выборки, а выбранные индексы соответствуют ожидаемым сценариям доступа к данным.
