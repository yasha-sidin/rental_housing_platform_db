# 02-migration

Раздел фиксирует применение схемы базы данных последовательной цепочкой миграций. Миграции выполняются после запуска кластера через служебный маршрут записи, поэтому DDL-команды попадают на текущий основной PostgreSQL-узел.

## Полученные артефакты

- `artifacts/migration_version.txt` - версия последней примененной миграции; значение `6` соответствует полному набору файлов `V001`-`V006`.
- журнал применения миграций - подтверждает, что мигратор выполнил изменения схемы без ручного подключения к конкретному PostgreSQL-узлу.
- проверка writer endpoint - подтверждает, что маршрут записи HAProxy ведет на основной узел кластера.

## Интерпретация

Артефакты показывают воспроизводимый порядок создания схемы: сначала поднимается кластер и слой маршрутизации, затем мигратор применяет DDL через стабильную точку записи. Такой порядок отделяет жизненный цикл схемы от физического размещения текущего основного узла.
