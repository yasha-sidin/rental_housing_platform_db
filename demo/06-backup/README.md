# 06-backup

Раздел фиксирует проверку резервного копирования через pgBackRest. Резервное копирование рассматривается отдельно от репликации, потому что репликация не защищает от логических ошибок и некорректных миграций.

## Полученные артефакты

- `artifacts/pgbackrest_full_backup.txt` - журнал создания полной резервной копии.
- `artifacts/pgbackrest_info.txt` - состояние раздела pgBackRest, список резервных копий и связанная информация о WAL.
- `artifacts/pgbackrest_check.txt` - результат проверки репозитория резервных копий, если проверка запускалась отдельно.

## Интерпретация

Артефакты показывают, что полный снимок данных создается через внешний контур pgBackRest, а репозиторий резервных копий доступен для последующего восстановления. Наличие полной резервной копии и архива WAL является основанием для восстановления на выбранный момент времени.
