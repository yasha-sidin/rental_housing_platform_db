# 01-domain

Раздел фиксирует проверку предметной области и доменных ограничений базы данных. В ходе проверки применяются справочники, демонстрационные пользователи, объявления, бронирования и SQL-тесты бизнес-инвариантов.

## Полученные артефакты

- `artifacts/domain_counts.txt` - контрольное количество ключевых доменных сущностей после загрузки seed-данных: пользователей, объявлений и бронирований.
- вывод `db/tests/001_domain_invariants.sql` - результат SQL-проверок, которые подтверждают ограничения модели: занятость дат, связь бронирования с платежом, допустимые статусы и правила отзывов.

## Интерпретация

Артефакты показывают, что база данных содержит не только таблицы, но и проверяемую доменную модель. Seed-данные создают воспроизводимое состояние, а SQL-тесты подтверждают, что важные для платформы аренды жилья правила выражены на уровне схемы и ограничений.
