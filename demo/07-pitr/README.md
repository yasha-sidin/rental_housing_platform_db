# 07-pitr

Раздел фиксирует проверку восстановления на выбранный момент времени. Сценарий моделирует логическую ошибку и восстановление отдельного узла на состояние до этой ошибки.

## Полученные артефакты

- `artifacts/next_steps.txt` - зафиксированный порядок действий для сценария восстановления на момент времени.
- точка восстановления или временная метка - момент, к которому должен быть восстановлен отдельный узел.
- ошибочный SQL-запрос - изменение, которое намеренно повреждает рабочие данные.
- журнал восстановления - вывод pgBackRest restore и запуска восстановительного узла.
- проверочный `SELECT` после восстановления - подтверждение, что восстановительный узел содержит данные до логической ошибки.

## Интерпретация

Артефакты показывают, что логическая ошибка не устраняется синхронной репликацией: она повторяется на всех рабочих узлах. Для анализа и возврата корректных данных используется отдельный восстановительный узел, поднятый из полной резервной копии и архива WAL.
