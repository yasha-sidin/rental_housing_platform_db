# План проверки проектных сценариев

План проверки определяет набор сценариев, по которым подтверждаются проектные решения: корректность доменной схемы, воспроизводимость миграций, отказоустойчивость PostgreSQL-кластера, независимость клиентских цепочек, сохранность подтвержденных транзакций, пригодность резервных копий и наблюдаемость.

## 01 - Доменная модель

Проверяется структура доменной модели, начальные данные и ограничения предметной области.

Артефакты:

- количество записей в основных таблицах;
- результаты SQL-проверок из `db/tests/`.

## 02 - Миграции

Проверяется применение миграций через маршрут записи `haproxy-client-a`.

Артефакты:

- текущая версия миграций;
- список примененных миграций;
- подтверждение, что маршрут записи ведет на основной узел.

## 03 - Автоматическое переключение

Проверяется автоматическое переключение после остановки основного PostgreSQL-узла.

Артефакты:

- состояние кластера до отказа;
- факт остановки основного узла;
- новый основной узел;
- успешная запись после переключения;
- измеренное `RTO` (`Recovery Time Objective`, целевое время восстановления).

## 04 - Отказ клиентской цепочки

Проверяется, что отказ `pgbouncer-client-a` или `haproxy-client-a` влияет только на клиента A и не нарушает работу клиента B, поскольку клиентские цепочки подключения разделены.

Артефакты:

- состояние остановленного компонента клиента A;
- результат неуспешного запроса клиента A;
- результат успешного SQL-запроса клиента B.

## 05 - RPO = 0 при синхронной репликации

Проверяется сохранность подтвержденной транзакции и остановка записи при недостатке синхронных реплик.

Артефакты:

- подтвержденная транзакция до отказа;
- состояние синхронных реплик;
- факт остановки записи при нарушении требования к двум синхронным подтверждениям.

## 06 - Резервное копирование

Проверяется создание полной резервной копии и состояние репозитория pgBackRest.

Артефакты:

- вывод команды создания полной резервной копии;
- результат `pgbackrest info`;
- результат `pgbackrest check`.

## 07 - Восстановление на выбранный момент времени

Проверяется восстановление отдельного восстановительного узла на момент до логической ошибки.

Артефакты:

- зафиксированная точка восстановления или временная метка;
- факт выполнения логически ошибочной операции;
- результат SQL-проверки на восстановительном узле.

## 08 - Наблюдаемость

Проверяется наличие метрик и диагностических интерфейсов для контроля PostgreSQL-узлов, Patroni, etcd, HAProxy, PgBouncer и контура резервного копирования.

Артефакты:

- состояние Percona Monitoring and Management;
- состояние статистики HAProxy;
- наблюдаемые признаки отказов, репликации и маршрутизации.
